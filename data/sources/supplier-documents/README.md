# Supplier documents

**Simulates:** Documents received from or about suppliers: quotations, PCF data sheets, authority notices.

Demo data, fictitious: every company, value and document here is invented (team Excel `data/source/Supplier_Dummy_Data_v2.xlsx`, plus `data/assumptions.json`). Generated by `npm run data:build`; do not edit by hand.

| Folder or file | Content |
|---|---|
| `quotations/` | 25 quotation PDFs |
| `pcf-datasheets/` | 11 PCF data sheets sent by suppliers |
| `certificates/` | 47 certificates (ISO 14001, SA8000, …) of the suppliers in current requests and orders |
| `authority-notices/` | 1 fine notice (proof of a legal violation, knock-out) |
| `documents.json` | Index of these PDFs with their text, so the evidence check can find a value on its page |
