# Rating partner

**Simulates:** A sustainability rating provider (style of EcoVadis): scores, LkSG risk, certificates, scorecards.

Demo data, fictitious: every company, value and document here is invented (team Excel `data/source/Supplier_Dummy_Data_v2.xlsx`, plus `data/assumptions.json`). Generated by `npm run data:build`; do not edit by hand.

| File | Content |
|---|---|
| `ratings.json` | 100 ratings: score 0–100, LkSG country risk, certificates, SBTi target, report, controversies, CO₂ data source |
| `scorecards/` | 90 scorecard PDFs, one per rated supplier |
| `rating-history.json` | 343 assessments: score per year, the current one first in the ratings |
| `certificates.json` | 170 certificates with validity (PDFs of the suppliers in current requests are in `supplier-documents/certificates/`) |
| `company-emissions.json` | Company-level emissions (CSRD style): Scope 1+2, CO₂ intensity per EUR, renewable energy share, transport distance, data completeness |
| `documents.json` | Index of the scorecards with their text |
