# Risk monitoring

**Simulates:** A supply-chain risk monitoring service (style of Prewave / IntegrityNext): alerts per supplier.

Demo data, fictitious. Generated by `npm run data:build`; do not edit by hand.

| File | Content |
|---|---|
| `alerts.json` | 39 alerts with date, severity and category |

Every alert restates a fact from the other systems (fine notice, controversy in the rating, LkSG country risk, certificate validity, rating history). Nothing new is invented about any supplier.
