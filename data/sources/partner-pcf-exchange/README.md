# PCF exchange

**Simulates:** A product footprint exchange (style of PACT / SAP SDX): CO₂ per piece with data quality.

Demo data, fictitious: every company, value and document here is invented (team Excel `data/source/Supplier_Dummy_Data_v2.xlsx`, plus `data/assumptions.json`). Generated by `npm run data:build`; do not edit by hand.

| File | Content |
|---|---|
| `footprints.json` | 26 product footprints (kg CO₂e per piece) with data-quality level, boundary, reference date and how each one arrived |

Data-quality levels (team data model): 1 Verified · 2 Supplier-specific · 3 Company estimate · 4 Industry average. Footprints that came as a document link to their data sheet in `supplier-documents/pcf-datasheets/`.
