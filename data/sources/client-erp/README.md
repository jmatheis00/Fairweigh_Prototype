# Client ERP

**Simulates:** The buyer's own ERP (style of SAP S/4HANA): supplier master, performance, quotations, purchase orders.

Demo data, fictitious: every company, value and document here is invented (team Excel `data/source/Supplier_Dummy_Data_v2.xlsx`, plus `data/assumptions.json`). Generated by `npm run data:build`; do not edit by hand.

| File | Content |
|---|---|
| `suppliers.json` | Supplier master and performance: 100 suppliers with status, spend, contract, lead time, on-time delivery, complaint rate, VAT and ERP ID |
| `quotations.json` | 25 quotations registered for the current requests (the PDFs are in `supplier-documents/`) |
| `purchase-orders.json` | 63 purchase orders of the three products, January 2025 to September 2026 |
| `purchase-requisitions.json` | 8 purchase requisitions for the buyer's work queue (5 open, the others started or closed as sample work) |
| `supplier-performance.json` | Vendor evaluation per supplier and month (1272 rows): deliveries, on-time deliveries, quality notifications, spend. The KPIs in suppliers.json are the sums of the last 12 months |
| `purchase-orders/` | 63 order PDFs, one per purchase order |
| `documents.json` | Index of the order PDFs with their text |
